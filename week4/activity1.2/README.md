This use case diagram presents a possible future version of the Money Exchange System with three roles. A User can create or delete an account, exchange currency, and view their own transactions. Account creation may require a CAPTCHA check.

A Financial Manager can manage exchange rates, roll back transactions, and create reports using retrieved transaction data. A System Administrator manages users and currencies and can also perform the Financial Manager's tasks. These roles separate everyday customer activities from financial and administrative responsibilities.
